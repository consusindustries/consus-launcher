# Contributing

Consus Launcher is open source so that anyone, especially the security teams of the organizations that run it, can read exactly what it does.

We are not accepting pull requests from outside Consus right now. That keeps every change reviewed by the people who answer for it in customer security reviews. It may change later.

What helps:

- **Bugs:** open an issue with your macOS version, the tool you clicked, and what happened.
- **Security issues:** do not open an issue; see [SECURITY.md](SECURITY.md).
- **Reading and building the code:** see the README's "Build from source" section.
