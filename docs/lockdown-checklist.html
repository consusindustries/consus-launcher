Lockdown checklist: desktop AI tools on the Consus gateway

Every setting the Consus Launcher applies, per application, so you can apply it yourself. Tick each box as you go. "Web off" is the default; the web on variant is noted where it differs.

Gateway and key

Agent behavior

Features off

Telemetry off

Still leaves the machine: the ChatGPT app's own update and product-analytics calls to OpenAI. The config file doesn't reach those; control them at the network edge.

4. Codex CLI

Profile: ~/.codex-consus-gateway/config.toml, launched with CODEX_HOME set to it. User's ~/.codex is untouched.

5. Pi

Profile: ~/.pi-consus-gateway/, launched with PI_CODING_AGENT_DIR set to it. User's ~/.pi is untouched.

Limits: Pi has no sandbox and no lock, so agent shell commands can always reach the network. Control it with a container or the network edge. First run downloads fd and ripgrep from GitHub (don't set PI_OFFLINE; search breaks without them).

6. Enforce it (so users can't undo it)

User-level files can be edited by the user. To lock them, push the same settings through device management. Generate these from the Consus portal's deployment page.
